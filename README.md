# TheAddon Installation Guide

## Download
Download the file that matches your **Among Us** edition:

- **Steam / Itch.io**  
  `MalumMenu-3.1.0-Steam-Itch.zip`

- **Microsoft Store / Epic Games / Xbox App**  
  `MalumMenu-3.1.0-MicrosoftStore-EpicGames-XboxApp.zip`

---

## Install

Open the `.zip` file you downloaded and copy **all files** inside.

Paste them directly into your **Among Us** game folder.

### Game Folder Locations

> **Steam**  
> Right-click **Among Us** in your Library  
> → `Manage`  
> → `Browse local files`

> **Epic Games Launcher**  
> Right-click **Among Us** in your Library  
> → `Manage`  
> → Click the folder icon in the Installation section

> **Itch.io**  
> Open the Itch.io app  
> → Right-click **Among Us** in your Library  
> → `Manage`  
> → `Open folder in Explorer`

> **Microsoft Store**  
> Open the Windows apps folder  
> *(Usually: `C:\Program Files\WindowsApps\`)*  
> → Search for `Among Us.exe`  
> → Right-click it  
> → `Open file location`
> → https://www.youtube.com/watch?v=qCeoEIy_vrw

> **Xbox App**  
> Right-click **Among Us** in your Library  
> → `Manage`  
> → Open the `FILES` tab  
> → `BROWSE...`  
> → Open the `Among Us` folder  
> → Open the `Content` folder

---

> **Linux (Debian/Ubuntu)**  
> Right-click **Among Us** in your Library  
> → `Properties`  
> → Open the `Compatibility` tab  
> - Enable: Force the use of a specific Steam Play compatibility tool

> → In the select-menu down below choose: Proton Experimental

> Right-click **Among Us** in your Library  
> → `Manage`  
> → `Browse local files`
> - Add all the (unzipped) files you got in the folder you opened.


---

## Launch

Start **Among Us** normally.

A console window should appear and automatically install the required files.

Wait until the installation finishes.

After that, **Among Us** will automatically open with **TheAddon** installed.

---

## Controls

> Press `DELETE` on your keyboard to open or close the GUI.
